# Петербургский квест — бот для Telegram

Квест-прогулка по Петербургу: 9 точек, кнопки, проверка ответов, финальная оценка.

Стек: `python-telegram-bot 21.6` (long polling) + `Flask` (заглушка-порт для Render).

---

## Почему на Render бот «не работал»

1. **Неверная команда запуска.** Render для Python по умолчанию запускает
   `gunicorn app:app`, а файл называется `bot.py` и `gunicorn` не установлен.
   Сервис падал на старте. Лечится строкой запуска `python bot.py`
   (она уже прописана в `render.yaml`).
2. **Бесплатный веб-сервис засыпает через 15 минут** без запросов.
   Long polling умирает вместе с процессом, бот молчит.
   Лечится внешним пингом (см. ниже) — это тратит бесплатные 750 ч/мес,
   а в месяце ~720 ч, так что одного сервиса хватает.

---

## Вариант 1. Починить текущий сервис на Render (быстро, 5 минут)

1. Зайти на [dashboard.render.com](https://dashboard.render.com) → открыть сервис.
2. **Settings → Build & Deploy → Start Command**: вписать `python bot.py`
   (если поле пустое — Render подставит `gunicorn app:app`, это и есть причина).
3. Там же **Health Check Path**: `/health`.
4. **Environment**: переменная `BOT_TOKEN` = токен от @BotFather.
5. **Manual Deploy → Deploy latest commit**, дождаться статуса `Live`.
6. В **Logs** должно быть: `Бот запущен, начинаю приём сообщений`.
7. Открыть `https://<имя-сервиса>.onrender.com/health` — должен вернуться `ok`.

## Вариант 2. Развернуть заново через render.yaml (если проще пересоздать)

1. Закоммитить `render.yaml` в репозиторий.
2. На Render: **New → Blueprint** → выбрать репозиторий.
3. Render сам прочитает `render.yaml` и спросит `BOT_TOKEN` — вставить токен.

---

## Чтобы бот не засыпал

Нужен любой бесплатный сервис-пингер, который раз в 5–10 минут открывает
`https://<имя-сервиса>.onrender.com/health`.

- [cron-job.org](https://cron-job.org) — бесплатно, интервал 5 минут.
- [UptimeRobot](https://uptimerobot.com) — бесплатно, интервал 5 минут.

Без пинга бот будет отвечать только пока сервис не уснул, а просыпаться
он будет лишь при открытии сайта вручную.

## Локальный запуск (для проверки)

```bash
python -m venv venv
venv\Scripts\activate          # Windows
pip install -r requirements.txt
set BOT_TOKEN=123456:ABC...    # Windows (PowerShell: $env:BOT_TOKEN="...")
python bot.py
```

⚠️ Нельзя одновременно держать бота запущенным локально и на Render —
Telegram отдаст одному из них ошибку `409 Conflict`, и оба начнут сбоить.
Для локальной проверки лучше взять **отдельного** тестового бота у @BotFather.

## Куда ещё можно переехать, если Render надоест

| Вариант | Плюсы | Минусы |
|---|---|---|
| Свой ПК (Windows) | бесплатно, код под рукой | ПК должен быть включён |
| VPS (Timeweb, Beget, Hetzner) | 24/7, ~150–300 ₽/мес | платно |
| Koyeb / Fly.io | без засыпания | нужна карта, лимиты |
| Render + пингер | 0 ₽ | сервис «просыпается» с задержкой |
