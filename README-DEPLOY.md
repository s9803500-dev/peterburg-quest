# Петербургский квест — бот для Telegram

Квест-прогулка по Петербургу: 9 точек, кнопки, проверка ответов, финальная оценка.

Стек: `python-telegram-bot 21.6` (long polling) + `Flask` (порт и `/health` для Render).

---

## Как устроен запуск

Бот стартует **при любой** команде запуска, которую может подставить Render:

| Команда в панели | Что происходит |
|---|---|
| `gunicorn app:app` (по умолчанию) | `app.py` отдаёт порт, бот крутится в фоновом потоке |
| `python bot.py` | Flask в потоке, бот в основном |
| `python app.py` | то же, что и выше |

Точка входа для gunicorn — переменная `app` в `app.py`.
Важно: воркер должен быть **один**, иначе Telegram вернёт `409 Conflict`.

## Почему бот «не работал»

1. Render для Python по умолчанию запускает `gunicorn app:app`. Файла `app.py`
   не было → сервис падал на старте. Теперь он есть.
2. Бесплатный веб-сервис засыпает через 15 минут без входящих запросов.
   Теперь `bot.py` сам пингует `RENDER_EXTERNAL_URL/health` каждые 10 минут —
   Render эту переменную подставляет автоматически, настраивать ничего не нужно.
   Если авто-пинг по какой-то причине не сработает, добавь внешний пингер
   ([cron-job.org](https://cron-job.org)) на `https://<сервис>.onrender.com/health`.

## Что должно быть в переменных окружения

| Ключ | Значение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |

`RENDER_EXTERNAL_URL` и `PORT` Render задаёт сам — трогать не нужно.

## Проверка, что всё живо

- `https://<сервис>.onrender.com/health` → ответ `ok`
- в логах Render: `Бот запущен, начинаю приём сообщений`
- бот отвечает на `/start` в Telegram

## Локальный запуск (для проверки)

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
set BOT_TOKEN=123456:ABC...
python bot.py
```

⚠️ Нельзя держать бота запущенным одновременно локально и на Render —
Telegram отдаст одному из них `409 Conflict`. Для проверок бери отдельного
тестового бота у @BotFather.

## Структура

```
bot.py           весь бот: тексты точек, кнопки, разбор ответов, авто-пинг
app.py           точка входа для gunicorn (Render по умолчанию)
requirements.txt зависимости
render.yaml      конфиг Render (команда запуска, health check)
.gitignore       чтобы токен и venv не попали в git
```
